About this build

Arbor · static front end (HTML, CSS, ES modules) · Firebase Auth and Firestore · Chart.js for charts.

Run it locally 
npm test                         # 13 logic tests: HFRI, finance, accounting, simulations
npx firebase-tools emulators:start --only hosting,firestore
cd backend && npm install && npm start   # optional: live stock quotes on :3000
Deploy 
npm run deploy                   # hosting + firestore.rules
# Stock quotes: deploy backend/ (or the Cloud Function) and set STOCK_API_URL in public/js/config.js
Project layout 
public/js/hfri.js          HFRI formulas, what-ifs, stress test
public/js/core-finance.js  personal finance numbers (single source of truth)
public/js/accounting.js    double-entry maths, final accounts
public/js/engine.js        seeded Monte Carlo + portfolio stats
public/js/pages/*.js       one controller per page
public/js/developer-config.js   edit this page's content
